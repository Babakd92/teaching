# Kentucky River Machine Learning Teaching Dashboard

This folder is ready to publish with GitHub Pages. The dashboard is contained in `index.html`; no installation or build step is required.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all three items from this folder to the repository's top level:
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then select **Save**.

GitHub will provide a public address similar to:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Notes

- Keep the filename `index.html`; GitHub Pages uses it as the home page.
- The dashboard, charts, data, and student-response tools are embedded in the HTML file.
- An internet connection is needed to display the interactive map background. The rest of the dashboard is included in `index.html`.
- Student responses are saved only in the browser being used. They are not uploaded to GitHub or a server.
